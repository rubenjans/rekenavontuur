# Reken Avontuur

Een Streamlit-spel voor het oefenen van sommen en verschillen.

## Functies
- Getallenbereiken: 0–10, 0–20, 0–50 en 0–100
- Sommen, verschillen of een combinatie
- Gewoon niveau, tijdsklok en toetsniveau
- Meerkeuze of zelf invullen; toetsniveau is altijd zelf invullen
- 100 oefeningen en 10 minuten in toetsniveau
- Mobiele layout met statistieken onderaan
- Geen klassement of opslag van persoonsgegevens

## Starten
```bash
pip install -r requirements.txt
streamlit run app.py
```
